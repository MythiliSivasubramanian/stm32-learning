# Timers and Interrupts (STM32) — Notes

## What is a Timer?

A timer is a hardware peripheral that counts clock ticks. It can be used to measure
time intervals, generate periodic events, or trigger actions after a delay.

### Common uses
- Blink an LED periodically
- Generate PWM for motor control or LED dimming
- Measure pulse widths (input capture)
- Schedule periodic tasks using interrupts

---

## Basic Timer concepts

- Clock source: timers run from a clock (APB timer clock).
- Prescaler (PSC): divides the timer clock to slow down counting.
- Auto-reload register (ARR): the counter top value; timer resets when CNT reaches ARR.
- Counter (CNT): current count value.

Timer frequency formula (simple):

Given timer input clock Fclk, prescaler PSC, and ARR:

Effective tick frequency: Ftick = Fclk / (PSC + 1)
Period (seconds) = (ARR + 1) / Ftick

Example: with Fclk=72MHz, PSC=7199, ARR=9999 → period ~1s (approx).

## Generating periodic interrupts

1. Configure PSC and ARR to set period.
2. Enable update interrupt (UIE) for the timer.
3. Start timer in interrupt mode.
4. Implement ISR/callback to handle events.

Simple HAL-style flow:

1. MX_TIM2_Init();
2. HAL_TIM_Base_Start_IT(&htim2);

In IRQ handler (auto-generated by cubeMX):

void TIM2_IRQHandler(void)
{
    HAL_TIM_IRQHandler(&htim2);
}

And the callback:

void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim)
{
    if (htim->Instance == TIM2)
    {
        // toggle LED or set flag
    }
}

---

## PWM (short)

- Use CCRx (capture/compare registers) to set duty cycle.
- Configure channel in PWM mode and start with HAL_TIM_PWM_Start().

---

## Practical tips

- Use integer math for PSC/ARR calculations to avoid floating point on small MCUs.
- Use a hardware timer for precise timing instead of delay loops.
- Keep ISR code short; set flags and handle heavy work in main loop or task.
