# Fundamentals

This folder contains core low-level concepts that form the foundation of Embedded Systems and STM32 programming.

My goal is to build strong understanding of:
- bitwise operations
- binary manipulation
- register-level thinking
- memory-related concepts
- low-level problem solving using C

---

## Topics Covered

- Bitwise AND (`&`)
- Bitwise OR (`|`)
- XOR (`^`)
- NOT (`~`)
- Left Shift (`<<`)
- Right Shift (`>>`)
- Setting bits
- Clearing bits
- Toggling bits
- Checking bits
- Memory organization in STM32
